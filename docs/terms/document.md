# 문헌 (Document)

- 분야: 기초 개념
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/document/
- 다른 이름: 도큐먼트

정보가 어떤 매체에 기록되어 하나의 단위로 다룰 수 있게 된 것입니다. 종이책만이 아니라 지도, 사진, 영상, 음원, 웹페이지, 전자 파일도 모두 문헌이 될 수 있습니다.

관련어: 정보(information), 단행본(monograph), 연속간행물(serial)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
