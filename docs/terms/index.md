# 색인 (Index)

- 분야: 분류와 주제
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/index/
- 다른 이름: 인덱스, 찾아보기

자료 안의 낱말이나 주제가 어디에 있는지 찾아갈 수 있도록 정리한 목록입니다. 책 뒤의 「찾아보기」, 여러 학술지 논문을 주제별로 찾게 해 주는 색인지, 검색엔진이 미리 만들어 두는 색인 모두 같은 원리입니다.

관련어: 시소러스(thesaurus), 초록(abstract), 인용색인(citation-index), 정보검색(information-retrieval)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
