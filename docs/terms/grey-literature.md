# 회색문헌 (Grey Literature)

- 분야: 장서와 자료
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/grey-literature/
- 다른 이름: 회색 문헌

일반 출판사·서점 유통을 거치지 않아 구하거나 찾기 어려운 자료입니다. 연구보고서, 정부·기관 보고서, 학술대회 발표 자료, 기술 문서, 학위논문 등이 여기에 들어갑니다.

관련어: 학위논문(thesis), 전문도서관(special-library), 기관 리포지터리(institutional-repository)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
