# 청구기호 (Call Number)

- 분야: 분류와 주제
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/call-number/

도서관에서 자료 하나하나가 서가의 어느 자리에 있는지를 알려 주는 기호입니다. 보통 분류기호와 도서기호를 합쳐 만들고, 필요하면 별치기호(보관 장소 표시), 권차, 복본기호를 덧붙입니다. 책등에 붙은 라벨이 바로 청구기호입니다.

예: 「813.7 김64ㅅ」 → 813.7(분류기호: 한국 소설 가운데 21세기 작품) + 김64ㅅ(도서기호: 저자와 서명).

관련어: 분류(classification), 도서기호(book-number), 한국십진분류법(kdc), 개가제(open-stacks)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
