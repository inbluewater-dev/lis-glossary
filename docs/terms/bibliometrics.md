# 계량서지학 (Bibliometrics)

- 분야: 학술정보와 저작권
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/bibliometrics/
- 다른 이름: 서지계량학

논문 수, 인용 횟수, 저자·학술지 분포 같은 서지 데이터를 숫자로 세고 분석해 학술 활동의 경향을 밝히는 연구 분야입니다.

관련어: 영향력지수(impact-factor), h지수(h-index), 브래드포드 법칙(bradfords-law), 인용색인(citation-index)
근거: S. C. Bradford, Sources of information on specific subjects (Engineering, 1934); E. Garfield, Citation Indexes for Science (Science, 1955) <https://doi.org/10.1126/science.122.3159.108>
