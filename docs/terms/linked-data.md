# 연결데이터 (Linked Data)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/linked-data/
- 다른 이름: 링크드 데이터, 링크드 오픈 데이터, LOD

데이터 하나하나에 웹 주소 형태의 고유 이름(URI)을 붙이고 데이터끼리의 관계를 표준 방식으로 적어, 웹 전체에서 서로 연결되고 기계가 읽을 수 있게 하는 방식입니다. 누구나 자유롭게 쓸 수 있게 공개한 것을 「링크드 오픈 데이터(LOD)」라고 부릅니다.

관련어: BIBFRAME(bibframe), 메타데이터(metadata), 전거제어(authority-control)
근거: Tim Berners-Lee, Linked Data — Design Issues (2006) <https://www.w3.org/DesignIssues/LinkedData.html>
