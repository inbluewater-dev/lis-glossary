# 인용색인 (Citation Index)

- 분야: 정보검색
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/citation-index/

어떤 논문이 어떤 논문을 인용했는지를 기록해, 인용 관계를 따라가며 자료를 찾을 수 있게 만든 색인입니다. 유진 가필드가 과학 분야의 인용색인을 처음 제안했고, 우리나라에는 한국연구재단의 한국학술지인용색인(KCI)이 있습니다.

관련어: 인용(citation), 영향력지수(impact-factor), 계량서지학(bibliometrics), 색인(index)
근거: E. Garfield, Citation Indexes for Science (Science, 1955) <https://doi.org/10.1126/science.122.3159.108>; 한국연구재단, 한국학술지인용색인(KCI) <https://www.kci.go.kr/>
