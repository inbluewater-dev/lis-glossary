# 메타데이터 (Metadata)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/metadata/

어떤 자료를 설명하는 데이터, 곧 「데이터에 관한 데이터」입니다. 책의 제목·저자, 사진의 촬영 날짜·장소, 파일의 크기·형식 등이 메타데이터이며, 자료를 찾고 관리하고 보존하는 데 쓰입니다.

예: 스마트폰 사진 파일 안에 저장된 촬영 일시와 위치 정보.

관련어: 더블린 코어(dublin-core), 서지 레코드(bibliographic-record), MARC(marc), 연결데이터(linked-data)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>; DCMI Metadata Terms / ISO 15836 <https://www.dublincore.org/>
