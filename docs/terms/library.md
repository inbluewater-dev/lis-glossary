# 도서관 (Library)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/library/

책을 비롯한 여러 자료를 모으고 정리하고 보존해서, 이용자가 읽고 배우고 연구할 수 있도록 제공하는 기관이나 시설입니다. 우리나라에서는 도서관법이 도서관의 종류와 역할을 정하고 있습니다.

관련어: 공공도서관(public-library), 학교도서관(school-library), 대학도서관(academic-library), 전문도서관(special-library), 국가도서관(national-library), 사서(librarian)
근거: 대한민국 도서관법 (국가법령정보센터) <https://www.law.go.kr/법령/도서관법>; ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
