# 주제목록 (Subject Cataloging)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/subject-cataloging/
- 다른 이름: 주제분석

목록작업 가운데 자료의 내용이 무엇에 관한 것인지 분석해 주제명을 붙이고 분류기호를 주는 부분입니다. 자료의 겉모습과 책임 관계를 다루는 기술목록과 짝을 이룹니다.

관련어: 기술목록(descriptive-cataloging), 주제명표목(subject-heading), 분류(classification)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
