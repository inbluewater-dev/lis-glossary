# 통제어휘 (Controlled Vocabulary)

- 분야: 분류와 주제
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/controlled-vocabulary/
- 다른 이름: 통제어

같은 개념을 하나의 정해진 말로만 쓰도록 미리 정해 놓은 어휘입니다. 「핸드폰·휴대폰·휴대전화」처럼 여러 표현이 있을 때 하나로 통일해, 검색 결과가 흩어지지 않게 합니다. 반대로 정하지 않고 쓰는 일상 낱말을 「자연어」라고 합니다.

관련어: 시소러스(thesaurus), 주제명표목(subject-heading), 전거제어(authority-control)
근거: ISO 25964 Thesauri and interoperability with other vocabularies <https://www.iso.org/standard/53657.html>
