# 참고면담 (Reference Interview)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/reference-interview/
- 다른 이름: 레퍼런스 인터뷰

이용자가 처음 꺼낸 질문 뒤에 있는 진짜 필요를 알아내기 위해 사서가 묻고 확인하는 대화입니다. 처음 질문이 막연하거나 실제 필요와 다른 경우가 많기 때문에 참고서비스의 핵심 단계로 여겨집니다.

관련어: 참고서비스(reference-service)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
