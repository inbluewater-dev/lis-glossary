# 3차 자료 (Tertiary Source)

- 분야: 기초 개념
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/tertiary-source/
- 다른 이름: 3차 문헌

1차·2차 자료를 다시 가려 뽑고 정리해, 어떤 분야를 빠르게 훑어보거나 2차 자료를 찾아가게 해 주는 자료입니다. 백과사전, 용어사전, 연감, 편람, 「서지의 서지」 등이 해당합니다. 이 용어사전도 3차 자료입니다. 분야마다 1·2·3차를 나누는 기준이 조금씩 다릅니다.

관련어: 1차 자료(primary-source), 2차 자료(secondary-source), 참고자료(reference-material)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
