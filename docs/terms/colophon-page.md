# 판권기 (Copyright Page / Imprint Page (Korean books))

- 분야: 책과 서지학
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/colophon-page/
- 다른 이름: 판권면, 판권지, 판권 페이지

우리 책의 맨 뒤(또는 앞)에 서명, 지은이, 펴낸이, 펴낸 곳, 펴낸 날과 판·쇄, ISBN 같은 정보를 모아 적어 둔 부분입니다. 옛 책의 「간기」가 하던 역할을 이어받은 것으로, 목록작업에서 발행사항과 판 정보를 확인하는 중요한 출처입니다.

관련어: 간기(colophon), 발행사항(imprint), 판(edition), 국제표준도서번호(isbn)
근거: 한국도서관협회, 한국목록규칙(KCR)
