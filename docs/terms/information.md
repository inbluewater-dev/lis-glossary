# 정보 (Information)

- 분야: 기초 개념
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/information/

어떤 사실이나 자료가 사람에게 의미를 갖도록 정리되어, 판단이나 행동에 쓰일 수 있게 된 것입니다. 숫자나 기호 같은 날것의 자료(데이터)가 맥락을 얻으면 정보가 되고, 정보가 쌓여 이해로 이어지면 지식이 된다고 흔히 설명합니다.

관련어: 문헌(document), 문헌정보학(library-and-information-science)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
