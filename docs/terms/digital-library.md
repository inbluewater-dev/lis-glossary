# 디지털도서관 (Digital Library)

- 분야: 디지털과 보존
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/digital-library/
- 다른 이름: 전자도서관

디지털 형태의 자료를 모아 정리하고, 인터넷으로 언제 어디서나 이용할 수 있게 제공하는 도서관 또는 서비스입니다.

관련어: 디지털화(digitization), 전자책(ebook), 디지털 보존(digital-preservation)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
