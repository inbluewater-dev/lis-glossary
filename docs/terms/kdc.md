# 한국십진분류법 (Korean Decimal Classification (KDC))

- 분야: 분류와 주제
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/kdc/
- 다른 이름: KDC

한국도서관협회가 만든 우리나라의 표준 분류표로, 국내 공공도서관과 학교도서관 대부분이 씁니다. 지식을 000 총류, 100 철학, 200 종교, 300 사회과학, 400 자연과학, 500 기술과학, 600 예술, 700 언어, 800 문학, 900 역사의 열 갈래로 나누고, 각 갈래를 다시 열로 나눕니다.

예: 우리나라 소설은 보통 813으로 분류합니다(800 문학 → 810 한국문학 → 813 소설).

관련어: 듀이십진분류법(ddc), 분류표(classification-scheme), 청구기호(call-number)
근거: 한국도서관협회, 한국십진분류법(KDC) 제6판 (2013)
