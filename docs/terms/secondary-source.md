# 2차 자료 (Secondary Source)

- 분야: 기초 개념
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/secondary-source/
- 다른 이름: 2차 문헌

1차 자료를 바탕으로 해석하거나 분석하거나 정리한 자료입니다. 역사책, 평론, 여러 연구를 모아 검토한 논문 등이 있습니다. 문헌정보학에서는 특히 서지·색인·초록처럼 1차 자료를 찾아가게 해 주는 자료를 2차 자료라고 부릅니다.

관련어: 1차 자료(primary-source), 3차 자료(tertiary-source), 서지(bibliography), 색인(index), 초록(abstract)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
