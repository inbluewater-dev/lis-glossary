# IFLA LRM (IFLA Library Reference Model)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/ifla-lrm/
- 다른 이름: 도서관 참조 모형

서지 정보가 무엇을 설명하는지를 개념적으로 정리한 국제도서관연맹(IFLA)의 모형입니다. 1998년의 FRBR 등 세 개의 모형을 2017년에 하나로 통합했으며, 작품을 「저작·표현형·구현형·개별자료」의 층으로 나누어 보는 생각이 핵심입니다.

관련어: 저작·표현형·구현형·개별자료(wemi), RDA(rda), BIBFRAME(bibframe)
근거: IFLA Library Reference Model (IFLA LRM), 2017 <https://repository.ifla.org/items/214c74cb-c075-4428-a138-39f8d06c55aa>
