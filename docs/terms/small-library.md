# 작은도서관 (Small Library)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/small-library/

아파트 단지, 주민센터, 종교시설 등 생활 가까운 곳에 작은 규모로 운영되는 공공도서관입니다. 도서관법에서 공공도서관의 한 종류로 정하고 있으며, 주민이 직접 운영하는 곳도 많습니다.

관련어: 공공도서관(public-library)
근거: 대한민국 도서관법 (국가법령정보센터) <https://www.law.go.kr/법령/도서관법>; 대한민국 작은도서관 진흥법 (국가법령정보센터)
