# 사서 (Librarian)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/librarian/

도서관에서 자료를 고르고 정리하며, 이용자가 필요한 정보를 찾도록 돕는 전문직입니다. 우리나라에서는 도서관법에 따라 1급 정사서, 2급 정사서, 준사서 자격이 있습니다.

관련어: 사서교사(teacher-librarian), 참고서비스(reference-service), 목록(catalog)
근거: 대한민국 도서관법 (국가법령정보센터) <https://www.law.go.kr/법령/도서관법>
