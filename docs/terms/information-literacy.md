# 정보리터러시 (Information Literacy)

- 분야: 기초 개념
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/information-literacy/
- 다른 이름: 정보활용능력, 정보문해력

정보가 필요하다는 것을 알아차리고, 그 정보를 찾아내고, 믿을 만한지 따져 보고, 올바르게 활용하는 능력입니다. 출처를 밝히고 저작권을 지키는 태도까지 포함하며, 학교도서관과 대학도서관 교육의 중심 목표입니다.

예: 과제 자료를 찾을 때 검색 결과의 작성자·날짜·근거를 확인하고, 쓴 자료의 출처를 적는 것.

관련어: 사서교사(teacher-librarian), 1차 자료(primary-source), 인용(citation), 저작권(copyright)
근거: American Library Association, Presidential Committee on Information Literacy: Final Report (1989) <https://www.ala.org/acrl/publications/whitepapers/presidential>; ACRL, Framework for Information Literacy for Higher Education (2015) <https://www.ala.org/sites/default/files/acrl/content/issues/infolit/framework1.pdf>
