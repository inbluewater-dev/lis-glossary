# 대학도서관 (Academic Library)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/academic-library/
- 다른 이름: 대학 도서관

대학의 교육과 연구를 지원하기 위해 대학 안에 둔 도서관입니다. 학술지, 학위논문, 학술 데이터베이스 같은 연구용 자료를 많이 갖추고 있습니다.

관련어: 학술지(academic-journal), 학위논문(thesis), 디스커버리 서비스(discovery-service), 기관 리포지터리(institutional-repository)
근거: 대한민국 대학도서관진흥법 (국가법령정보센터) <https://www.law.go.kr/법령/대학도서관진흥법>; 대한민국 도서관법 (국가법령정보센터) <https://www.law.go.kr/법령/도서관법>
