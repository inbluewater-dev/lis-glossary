# 문헌정보학 (Library and Information Science (LIS))

- 분야: 기초 개념
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/library-and-information-science/
- 다른 이름: 도서관학

기록된 지식과 정보를 모으고, 정리하고, 보존하고, 필요한 사람에게 찾아 주는 일을 연구하는 학문입니다. 도서관을 다루는 도서관학에서 출발해, 지금은 기록관리·정보검색·메타데이터·디지털 정보까지 넓게 다룹니다.

관련어: 도서관(library), 정보(information), 정보검색(information-retrieval), 메타데이터(metadata)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
