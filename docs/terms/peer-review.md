# 동료심사 (Peer Review)

- 분야: 학술정보와 저작권
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/peer-review/
- 다른 이름: 동료평가, 피어 리뷰

논문을 학술지에 싣기 전에 같은 분야의 다른 전문가들이 내용을 검토해 실을지 말지를 판단하는 과정입니다. 연구의 질을 지키는 장치로, 심사자와 저자가 서로 누구인지 모르게 하는 경우가 많습니다.

관련어: 학술지(academic-journal), 오픈액세스(open-access)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
