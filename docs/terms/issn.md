# 국제표준연속간행물번호 (International Standard Serial Number (ISSN))

- 분야: 식별자와 표준
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/issn/
- 다른 이름: ISSN

잡지·학술지·신문 같은 연속간행물에 붙이는 8자리 고유 번호입니다. 네 자리씩 하이픈으로 나누어 쓰며(예: 1234-5678), 마지막 자리는 검사용 숫자라 X가 올 수도 있습니다.

관련어: 연속간행물(serial), 국제표준도서번호(isbn), 학술지(academic-journal)
근거: ISSN International Centre / ISO 3297 <https://www.issn.org/>; 국립중앙도서관 <https://www.nl.go.kr/>
