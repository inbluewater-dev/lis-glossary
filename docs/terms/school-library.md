# 학교도서관 (School Library)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/school-library/

초·중·고등학교 안에 두어 학생과 교사의 수업, 독서, 탐구 활동을 지원하는 도서관입니다. 학교도서관진흥법이 설치와 운영의 기준을 정하고 있습니다.

관련어: 사서교사(teacher-librarian), 정보리터러시(information-literacy), 도서관(library)
근거: 대한민국 학교도서관진흥법 (국가법령정보센터) <https://www.law.go.kr/법령/학교도서관진흥법>; IFLA School Library Guidelines, 2nd ed. (2015) <https://repository.ifla.org/handle/123456789/58>
