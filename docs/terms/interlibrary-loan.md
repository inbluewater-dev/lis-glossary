# 상호대차 (Interlibrary Loan (ILL))

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/interlibrary-loan/

내가 다니는 도서관에 없는 자료를 다른 도서관에서 빌려 와 이용할 수 있게 해 주는 도서관끼리의 협력 서비스입니다. 국립중앙도서관의 「책바다」처럼 전국 단위로 운영하는 서비스도 있습니다.

관련어: 대출(lending), 도서관(library), 종합목록(union-catalog)
근거: 국립중앙도서관 <https://www.nl.go.kr/>
