# 정확률 (Precision)

- 분야: 정보검색
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/precision/
- 다른 이름: 정도율

검색되어 나온 자료 가운데 실제로 적합한 자료의 비율입니다. 정확률이 높으면 쓸데없는 결과가 적다는 뜻입니다. 계산식은 「검색된 적합 자료 수 ÷ 검색된 전체 자료 수」입니다. 보통 재현율을 높이면 정확률이 떨어지고, 정확률을 높이면 재현율이 떨어지는 경향이 있습니다.

관련어: 재현율(recall), 정보검색(information-retrieval)
근거: C. D. Manning, P. Raghavan, H. Schütze, Introduction to Information Retrieval (Cambridge University Press, 2008) <https://nlp.stanford.edu/IR-book/>
