# 보존 (Preservation)

- 분야: 디지털과 보존
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/preservation/
- 다른 이름: 자료보존, 보존관리

자료가 손상되지 않고 오래 이용될 수 있도록 보호하는 모든 활동입니다. 알맞은 온도·습도 유지, 빛과 해충 차단, 산성 종이를 중화하는 탈산 처리, 찢어진 곳 수선, 디지털화 등이 포함됩니다.

관련어: 디지털 보존(digital-preservation), 고서(old-book), 디지털화(digitization), 아카이브(archives)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
