# 디스커버리 서비스 (Discovery Service)

- 분야: 정보검색
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/discovery-service/
- 다른 이름: 통합검색, 웹 스케일 디스커버리

도서관이 가진 책과 구독 중인 전자저널·데이터베이스·논문을 한 번의 검색으로 함께 찾아 주는 통합 검색 서비스입니다. 대학도서관 홈페이지의 검색창이 대부분 이 방식입니다.

관련어: OPAC(opac), 대학도서관(academic-library), 패싯 분류(facet-classification)
근거: 새로 쓴 설명(특정 표준에 기대지 않음)
