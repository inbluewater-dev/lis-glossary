# 공공도서관 (Public Library)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/public-library/

지역 주민 누구나 나이·직업·배경에 상관없이 이용할 수 있는 도서관입니다. 주로 국가나 지방자치단체가 세워 운영하며, 개인이나 단체가 세운 사립 공공도서관도 있습니다. 책을 빌려주는 일뿐 아니라 독서 프로그램, 강좌, 정보 접근 지원 등 지역의 배움터 역할을 합니다.

관련어: 도서관(library), 작은도서관(small-library), 대출(lending)
근거: 대한민국 도서관법 (국가법령정보센터) <https://www.law.go.kr/법령/도서관법>; IFLA-UNESCO Public Library Manifesto (2022) <https://www.ifla.org/public-library-manifesto/>
