# ISBD (International Standard Bibliographic Description)

- 분야: 목록규칙과 표목
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/isbd/
- 다른 이름: 국제표준서지기술

국제도서관연맹(IFLA)이 정한 서지 기술의 국제 표준입니다. 어떤 정보를 어떤 순서로, 어떤 구두점(예: 제목과 저자 사이의 「 / 」)으로 구분해 적을지를 정해, 나라와 언어가 달라도 서지 정보를 알아볼 수 있게 합니다.

관련어: 한국목록규칙(kcr), 목록(catalog), 서지 레코드(bibliographic-record)
근거: IFLA, ISBD: International Standard Bibliographic Description, Consolidated Edition (2011) <https://www.ifla.org/isbd-editions/>
