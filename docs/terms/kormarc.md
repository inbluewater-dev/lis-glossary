# KORMARC (Korean MARC)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/kormarc/
- 다른 이름: 한국문헌자동화목록형식, 코마크

MARC를 우리나라 실정에 맞게 만든 서지 데이터 형식입니다. 국가표준(KS X 6006)으로 정해져 있으며, 국내 대부분의 도서관 목록이 이 형식으로 만들어집니다.

관련어: MARC(marc), 한국목록규칙(kcr), 국가도서관(national-library)
근거: KS X 6006 한국문헌자동화목록형식(KORMARC) — 국립중앙도서관 안내 <https://librarian.nl.go.kr/LI/contents/L10101000000.do>; 국립중앙도서관 <https://www.nl.go.kr/>
