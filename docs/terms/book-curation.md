# 북큐레이션 (Book Curation)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/book-curation/
- 다른 이름: 도서 큐레이션, 주제 전시

특정 주제나 독자, 시기에 맞춰 책을 골라 묶고 소개하는 일입니다. 도서관의 주제별 전시, 추천 목록, 테마 서가 등이 북큐레이션의 예입니다.

예: 수능이 끝난 뒤 「고3을 위한 쉼표 책」 코너를 만드는 것.

관련어: 장서(collection), 공공도서관(public-library), 학교도서관(school-library)
근거: 새로 쓴 설명(특정 표준에 기대지 않음)
