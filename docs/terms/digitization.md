# 디지털화 (Digitization)

- 분야: 디지털과 보존
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/digitization/
- 다른 이름: 디지털 변환

종이책, 사진, 필름, 음반 같은 아날로그 자료를 스캔하거나 촬영해 디지털 파일로 바꾸는 일입니다. 원본을 덜 만지게 해 보존에 도움이 되고, 멀리 있는 사람도 볼 수 있게 해 줍니다.

관련어: 디지털도서관(digital-library), 고서(old-book), 보존(preservation), 디지털 보존(digital-preservation)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
