# RFID (Radio-Frequency Identification)

- 분야: 식별자와 표준
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/rfid/
- 다른 이름: 무선인식, 전자태그

무선 신호로 태그의 정보를 읽어 내는 기술입니다. 도서관에서는 책에 붙인 RFID 태그로 무인 대출·반납, 분실 방지, 장서 점검을 빠르게 합니다.

관련어: 대출(lending), 장서(collection)
근거: ISO 28560 Information and documentation — RFID in libraries
