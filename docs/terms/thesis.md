# 학위논문 (Thesis / Dissertation)

- 분야: 장서와 자료
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/thesis/

석사나 박사 학위를 받기 위해 제출하는 연구 논문입니다. 대학도서관과 국회도서관 등이 수집하며, 상당수가 온라인으로 원문을 제공합니다.

관련어: 회색문헌(grey-literature), 대학도서관(academic-library), 기관 리포지터리(institutional-repository)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
