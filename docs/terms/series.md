# 총서 (Series)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/series/
- 다른 이름: 총서사항, 시리즈

각각 제목을 가진 여러 자료를 하나의 공통 제목 아래 묶어 펴내는 것, 또는 그 공통 제목입니다. 목록에서는 총서명과 총서 안의 번호를 따로 기록해, 같은 총서에 속한 책을 모아 찾을 수 있게 합니다.

예: 「(세계문학전집 ; 1)」은 「세계문학전집」이라는 총서의 1번이라는 뜻입니다.

관련어: 서지기술 영역(isbd-areas), 연속간행물(serial), 종합표제(collective-title)
근거: IFLA, ISBD: International Standard Bibliographic Description, Consolidated Edition (2011) <https://www.ifla.org/isbd-editions/>
