# MARC (Machine-Readable Cataloging)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/marc/
- 다른 이름: 마크, MARC 21

서지 정보를 컴퓨터가 읽고 주고받을 수 있도록 정한 데이터 형식입니다. 1960년대 미국 의회도서관에서 개발했고, 지금은 MARC 21이 널리 쓰입니다. 정보마다 세 자리 숫자 태그를 붙이는데, 예를 들어 245는 제목을 적는 자리입니다.

관련어: KORMARC(kormarc), 서지 레코드(bibliographic-record), BIBFRAME(bibframe), 메타데이터(metadata)
근거: Library of Congress, MARC 21 Formats <https://www.loc.gov/marc/>
