# 부출표목 (Added Entry)

- 분야: 목록규칙과 표목
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/added-entry/
- 다른 이름: 부출기입

기본표목 말고도, 공저자·옮긴이·총서명·다른 표제 등으로도 자료를 찾을 수 있도록 덧붙이는 표목입니다. MARC에서는 7XX 필드(예: 700 개인명 부출표목)에 기록합니다.

관련어: 기본표목(main-entry), 기입(entry), 표목(heading), 접근점(access-point)
근거: Anglo-American Cataloguing Rules, 2nd ed. (AACR2); Library of Congress, MARC 21 Formats <https://www.loc.gov/marc/>
