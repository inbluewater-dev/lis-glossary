# 불리언 검색 (Boolean Search)

- 분야: 정보검색
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/boolean-search/
- 다른 이름: 논리연산 검색, 불 검색

AND(그리고), OR(또는), NOT(빼기) 같은 논리 연산자로 검색어를 조합해 결과를 좁히거나 넓히는 검색 방법입니다.

예: 「기후변화 AND 청소년」은 두 낱말이 모두 들어간 자료, 「영화 OR 드라마」는 둘 중 하나라도 들어간 자료를 찾습니다.

관련어: 절단검색(truncation), 정보검색(information-retrieval)
근거: C. D. Manning, P. Raghavan, H. Schütze, Introduction to Information Retrieval (Cambridge University Press, 2008) <https://nlp.stanford.edu/IR-book/>
