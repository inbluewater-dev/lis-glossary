# 단행본 (Monograph)

- 분야: 장서와 자료
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/monograph/

한 권으로 끝나거나, 정해진 몇 권으로 완결되는 출판물입니다. 계속 이어서 나오는 잡지·신문 같은 연속간행물과 구별할 때 쓰는 말입니다.

관련어: 연속간행물(serial), 국제표준도서번호(isbn), 판(edition)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>; IFLA, ISBD: International Standard Bibliographic Description, Consolidated Edition (2011) <https://www.ifla.org/isbd-editions/>
