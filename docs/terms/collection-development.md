# 장서개발 (Collection Development)

- 분야: 장서와 자료
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/collection-development/
- 다른 이름: 장서관리, 컬렉션 개발

도서관이 이용자에게 필요한 자료를 계획적으로 고르고 사들이고, 평가하고, 낡은 자료를 정리하는 전체 과정입니다. 어떤 자료를 어떤 기준으로 모을지 적어 둔 문서를 「장서개발정책」이라고 합니다.

관련어: 장서(collection), 수서(acquisitions), 제적(weeding)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
