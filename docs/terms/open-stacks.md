# 개가제 (Open Stacks / Open Access Shelving)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/open-stacks/
- 다른 이름: 개가식

이용자가 서가에 직접 가서 책을 꺼내 보고 고를 수 있게 하는 운영 방식입니다. 반대로 이용자가 신청하면 직원이 서고에서 꺼내다 주는 방식을 폐가제라고 하며, 귀중한 자료나 오래된 자료에 주로 씁니다.

관련어: 청구기호(call-number), 보존(preservation)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
