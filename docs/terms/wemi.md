# 저작·표현형·구현형·개별자료 (Work, Expression, Manifestation, Item (WEMI))

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/wemi/

하나의 작품을 네 층으로 나누어 보는 IFLA LRM의 개념입니다. 저작은 작품 자체의 생각, 표현형은 특정 언어나 형태로 나타난 모습(예: 번역본), 구현형은 특정 출판사가 펴낸 판, 개별자료는 손에 쥐는 책 한 권입니다.

예: 『어린 왕자』(저작) → 어느 번역가의 한국어 번역(표현형) → 그 번역의 특정 출판사 판(구현형) → 우리 학교 도서관에 꽂힌 그 책 한 권(개별자료).

관련어: IFLA LRM(ifla-lrm), 판(edition)
근거: IFLA Library Reference Model (IFLA LRM), 2017 <https://repository.ifla.org/items/214c74cb-c075-4428-a138-39f8d06c55aa>
