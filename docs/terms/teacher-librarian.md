# 사서교사 (Teacher Librarian)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/teacher-librarian/

교사 자격과 사서 전문성을 함께 갖추고 학교도서관을 운영하며, 독서교육과 정보리터러시 교육을 맡는 교사입니다.

관련어: 학교도서관(school-library), 정보리터러시(information-literacy), 사서(librarian)
근거: 대한민국 학교도서관진흥법 (국가법령정보센터) <https://www.law.go.kr/법령/학교도서관진흥법>; 대한민국 초·중등교육법 (국가법령정보센터); IFLA School Library Guidelines, 2nd ed. (2015) <https://repository.ifla.org/handle/123456789/58>
