# 국제표준도서번호 (International Standard Book Number (ISBN))

- 분야: 식별자와 표준
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/isbn/
- 다른 이름: ISBN

책마다 붙이는 세계 공통의 고유 번호입니다. 2007년부터 13자리로 쓰며, 책 뒤표지 바코드 위에서 볼 수 있습니다. 우리나라는 국립중앙도서관 한국서지표준센터가 발급하고, 독자 대상·발행 형태·내용 분류를 나타내는 5자리 부가기호를 함께 씁니다.

예: 978-89-…, 979-11-…로 시작하는 번호는 우리나라에서 발행된 책입니다.

관련어: 국제표준연속간행물번호(issn), 출판예정도서목록(cip), 단행본(monograph), 판(edition)
근거: International ISBN Agency / ISO 2108 <https://www.isbn-international.org/>; 국립중앙도서관 <https://www.nl.go.kr/>
