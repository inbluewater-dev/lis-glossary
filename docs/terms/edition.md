# 판 (Edition)

- 분야: 장서와 자료
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/edition/
- 다른 이름: 판차

같은 원고로 같은 모양을 갖추어 펴낸 책 전체를 묶어 부르는 단위입니다. 내용이나 체제를 고쳐 다시 내면 「개정판」처럼 새로운 판이 되고, 내용을 그대로 두고 더 찍어 내기만 하면 판은 같고 「쇄」만 늘어납니다.

예: 「제3판 2쇄」는 세 번째 판을 두 번째로 찍은 책이라는 뜻입니다.

관련어: 단행본(monograph), 국제표준도서번호(isbn), 저작·표현형·구현형·개별자료(wemi)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>; IFLA, ISBD: International Standard Bibliographic Description, Consolidated Edition (2011) <https://www.ifla.org/isbd-editions/>
