# 본표제 (Title Proper)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/title-proper/
- 다른 이름: 본서명

자료의 대표 이름으로 기록하는 주된 표제입니다. 다른 언어로 나란히 적힌 표제는 「대등표제」, 본표제를 보충하는 부제목은 「부표제(표제관련정보)」라고 해서 따로 기록합니다.

예: 『코스모스: 우주의 기원과 진화』라면 「코스모스」가 본표제, 「우주의 기원과 진화」가 부표제입니다.

관련어: 책임표시(statement-of-responsibility), 종합표제(collective-title), 통일표제(uniform-title), 서지기술 영역(isbd-areas)
근거: IFLA, ISBD: International Standard Bibliographic Description, Consolidated Edition (2011) <https://www.ifla.org/isbd-editions/>; 한국도서관협회, 한국목록규칙(KCR)
