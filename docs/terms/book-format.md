# 판형 (Format (Bibliographical))

- 분야: 책과 서지학
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/book-format/
- 다른 이름: 2절판, 4절판, 8절판, folio, quarto, octavo

서지학에서 인쇄용 전지를 몇 번 접어 책을 만들었는지에 따른 책의 형태입니다. 한 번 접어 2장(4쪽)이 되면 2절판(folio), 두 번 접어 4장이면 4절판(quarto, 4to), 세 번 접어 8장이면 8절판(octavo, 8vo)입니다. 실제 크기(cm)를 뜻하는 「크기」와는 구별해 씁니다.

관련어: 시그니처(signature-mark), 고서(old-book), 판(edition)
근거: Philip Gaskell, A New Introduction to Bibliography (Oxford University Press, 1972)
