# 기관 리포지터리 (Institutional Repository (IR))

- 분야: 학술정보와 저작권
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/institutional-repository/
- 다른 이름: 기관 저장소, 리포지터리

대학이나 연구기관이 소속 구성원의 논문, 보고서, 데이터 같은 연구 결과를 모아 보존하고 온라인으로 공개하는 저장소입니다.

관련어: 오픈액세스(open-access), OAI-PMH(oai-pmh), 학위논문(thesis), 회색문헌(grey-literature)
근거: Open Archives Initiative Protocol for Metadata Harvesting (OAI-PMH) <https://www.openarchives.org/pmh/>; Budapest Open Access Initiative (2002) <https://www.budapestopenaccessinitiative.org/>
