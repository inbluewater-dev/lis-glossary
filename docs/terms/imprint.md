# 발행사항 (Imprint / Publication Statement)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/imprint/
- 다른 이름: imprint, 출판사항, publication statement

자료가 어디서, 누구에 의해, 언제 펴내졌는지(발행지·발행처·발행년)를 적는 부분입니다. ISBD에서는 제4영역인 「발행·제작·배포 등」에 해당하며, MARC에서는 260 필드(RDA에서는 264 필드)에 기록합니다. 우리 책에서는 주로 판권기에서 이 정보를 확인합니다.

관련어: 서지기술 영역(isbd-areas), 판권기(colophon-page), 간기(colophon), 판(edition)
근거: IFLA, ISBD: International Standard Bibliographic Description, Consolidated Edition (2011) <https://www.ifla.org/isbd-editions/>; Library of Congress, MARC 21 Formats <https://www.loc.gov/marc/>
