# OPAC (Online Public Access Catalog)

- 분야: 정보검색
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/opac/
- 다른 이름: 온라인 열람목록, 소장자료 검색

이용자가 컴퓨터나 스마트폰으로 도서관 소장 자료를 검색할 수 있게 공개한 온라인 목록입니다. 책이 있는지, 어디에 꽂혀 있는지(청구기호), 지금 빌릴 수 있는지를 확인할 수 있습니다.

관련어: 목록(catalog), 디스커버리 서비스(discovery-service), 청구기호(call-number)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
