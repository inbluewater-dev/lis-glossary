# 목록 (Catalog / Catalogue)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/catalog/
- 다른 이름: 도서관 목록, 목록작업

도서관이 가진 자료를 찾을 수 있도록 각 자료의 정보를 일정한 규칙에 따라 기록해 모아 놓은 것입니다. 예전에는 카드 목록을 썼고 지금은 대부분 컴퓨터 목록(OPAC)을 씁니다. 자료를 보고 그 기록을 만드는 일을 「목록작업」이라고 합니다.

관련어: 서지 레코드(bibliographic-record), OPAC(opac), 한국목록규칙(kcr), RDA(rda)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>; IFLA, ISBD: International Standard Bibliographic Description, Consolidated Edition (2011) <https://www.ifla.org/isbd-editions/>
