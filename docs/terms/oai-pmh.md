# OAI-PMH (Open Archives Initiative Protocol for Metadata Harvesting)

- 분야: 식별자와 표준
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/oai-pmh/

여러 저장소(리포지터리)의 메타데이터를 한곳에서 자동으로 모아 갈 수 있게(하베스팅) 해 주는 규약입니다. 대학의 기관 리포지터리에 올린 논문 정보를 통합 검색 서비스가 수집해 가는 데 쓰입니다. 기본 형식으로 더블린 코어를 씁니다.

관련어: 기관 리포지터리(institutional-repository), 더블린 코어(dublin-core), Z39.50(z3950)
근거: Open Archives Initiative Protocol for Metadata Harvesting (OAI-PMH) <https://www.openarchives.org/pmh/>
