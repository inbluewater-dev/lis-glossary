# 한정어구 (Qualifier / Qualifying Phrase)

- 분야: 목록규칙과 표목
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/qualifier/
- 다른 이름: 한정어, qualifying phrases, qualifiers

이름이나 표제, 주제명이 같아 서로 다른 대상을 구별하기 어려울 때, 표목(접근점) 뒤에 덧붙여 뜻을 좁혀 주는 낱말이나 구입니다. 괄호 안에 생몰년, 직업, 장소, 분야, 회의 차수·연도 등을 넣거나, 인명 뒤에 작위·직함 같은 말을 덧붙여 구별합니다.

예: 미국 의회도서관 주제명표목표의 「Mercury (Planet)」는 괄호 속 한정어구로 원소 수은이 아닌 행성 수성임을 나타냅니다.

관련어: 표목(heading), 접근점(access-point), 전거제어(authority-control), 주제명표목(subject-heading), 통일표제(uniform-title)
근거: Anglo-American Cataloguing Rules, 2nd ed. (AACR2); RDA: Resource Description and Access (RDA Toolkit) <https://www.rdatoolkit.org/>; Library of Congress Subject Headings (LCSH) <https://id.loc.gov/authorities/subjects.html>
