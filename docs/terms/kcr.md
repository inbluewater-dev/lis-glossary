# 한국목록규칙 (Korean Cataloging Rules (KCR))

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/kcr/
- 다른 이름: KCR

우리나라 도서관이 자료의 서지 정보를 기록할 때 따르는 목록 규칙입니다. 한국도서관협회가 만들어 왔으며, 국제 기준인 ISBD와 RDA 등의 흐름을 반영해 개정되어 왔습니다.

관련어: 목록(catalog), ISBD(isbd), RDA(rda), KORMARC(kormarc)
근거: 한국도서관협회, 한국목록규칙(KCR)
