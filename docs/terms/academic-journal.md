# 학술지 (Academic Journal / Scholarly Journal)

- 분야: 장서와 자료
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/academic-journal/
- 다른 이름: 저널, journals, journal

연구자들이 연구 결과를 논문으로 발표하는 연속간행물입니다. 대부분 다른 전문가의 동료심사를 거친 논문을 싣습니다.

관련어: 동료심사(peer-review), 연속간행물(serial), 영향력지수(impact-factor), 오픈액세스(open-access)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
