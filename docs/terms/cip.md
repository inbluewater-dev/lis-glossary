# 출판예정도서목록 (Cataloging in Publication (CIP))

- 분야: 식별자와 표준
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/cip/
- 다른 이름: CIP

책이 나오기 전에 국가도서관이 미리 만들어 출판사에 주는 서지 정보입니다. 책에 함께 실리거나 공유되어, 도서관들이 책을 받자마자 빠르게 목록을 만들 수 있게 돕습니다.

관련어: 국제표준도서번호(isbn), 목록(catalog), 국가도서관(national-library)
근거: 국립중앙도서관 <https://www.nl.go.kr/>
