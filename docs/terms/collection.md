# 장서 (Collection)

- 분야: 장서와 자료
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/collection/
- 다른 이름: 소장자료, 컬렉션

한 도서관이 가지고 있는 자료 전체입니다. 종이책뿐 아니라 잡지, 영상, 전자책, 구독 중인 데이터베이스까지 포함해 말하기도 합니다.

관련어: 장서개발(collection-development), 수서(acquisitions), 제적(weeding)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
