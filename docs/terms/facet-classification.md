# 패싯 분류 (Faceted Classification)

- 분야: 분류와 주제
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/facet-classification/
- 다른 이름: 분석합성식 분류, 패싯

주제를 여러 측면(패싯)으로 쪼갠 뒤, 필요한 측면들을 조합해 분류 기호를 만드는 방식입니다. 랑가나단의 콜론분류법(1933)이 대표적이며, 온라인 쇼핑몰에서 「가격·색상·크기」로 걸러 보는 패싯 검색도 같은 생각에서 나왔습니다.

관련어: 국제십진분류법(udc), 랑가나단의 도서관학 5법칙(five-laws-of-library-science), 디스커버리 서비스(discovery-service)
근거: S. R. Ranganathan, Colon Classification (1933)
