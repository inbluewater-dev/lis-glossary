# 인용 (Citation)

- 분야: 학술정보와 저작권
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/citation/

글을 쓸 때 다른 사람의 글이나 생각을 가져다 쓰고 그 출처를 밝히는 것입니다. 출처를 밝혀야 읽는 사람이 원래 자료를 확인할 수 있고, 원저작자의 노력을 인정할 수 있습니다. 출처를 밝히지 않고 가져다 쓰면 표절이 됩니다.

관련어: 서지(bibliography), 인용색인(citation-index), 저작권(copyright), 디지털객체식별자(doi)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
