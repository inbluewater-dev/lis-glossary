# 재현율 (Recall)

- 분야: 정보검색
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/recall/
- 다른 이름: 검색률

찾아야 할 적합한 자료 전체 가운데 실제로 검색되어 나온 비율입니다. 재현율이 높으면 빠뜨린 자료가 적다는 뜻입니다. 계산식은 「검색된 적합 자료 수 ÷ 전체 적합 자료 수」입니다.

관련어: 정확률(precision), 정보검색(information-retrieval)
근거: C. D. Manning, P. Raghavan, H. Schütze, Introduction to Information Retrieval (Cambridge University Press, 2008) <https://nlp.stanford.edu/IR-book/>
