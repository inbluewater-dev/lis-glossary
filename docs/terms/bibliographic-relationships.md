# 서지적 관계 (Bibliographic Relationships)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/bibliographic-relationships/

서로 다른 자료나 저작 사이의 관계입니다. 바바라 틸렛(Barbara Tillett)은 이를 동등(같은 내용의 복제·재쇄), 파생(번역·개작), 기술(비평·해설), 전체-부분, 딸림(부록·해답집), 연속(속편·후속 간행물), 공통 특성의 일곱 가지로 정리했습니다. 이런 관계를 기록하면 목록이 단순한 찾기 목록을 넘어, 한 저작의 여러 판과 번역과 해설서를 함께 보여 줄 수 있습니다.

관련어: 저작·표현형·구현형·개별자료(wemi), IFLA LRM(ifla-lrm), 통일표제(uniform-title), 참조(cross-reference)
근거: Barbara B. Tillett, Bibliographic Relationships: Toward a Conceptual Structure of Bibliographic Information Used in Cataloging (박사학위논문, UCLA, 1987); IFLA Library Reference Model (IFLA LRM), 2017 <https://repository.ifla.org/items/214c74cb-c075-4428-a138-39f8d06c55aa>; Michael Carpenter, Elaine Svenonius (eds.), Foundations of Cataloging: A Sourcebook (Libraries Unlimited, 1985)
