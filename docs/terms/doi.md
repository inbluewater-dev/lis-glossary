# 디지털객체식별자 (Digital Object Identifier (DOI))

- 분야: 식별자와 표준
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/doi/
- 다른 이름: DOI

학술 논문 같은 디지털 자료에 붙이는 영구 식별자입니다. 웹 주소가 바뀌어도 DOI는 그대로라서, 「https://doi.org/」 뒤에 DOI를 붙이면 자료가 옮겨 가도 계속 찾아갈 수 있습니다. 「10.」으로 시작합니다.

관련어: 인용(citation), ORCID(orcid), 학술지(academic-journal)
근거: DOI Foundation / ISO 26324 <https://www.doi.org/>
