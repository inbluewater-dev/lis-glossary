# 디지털 보존 (Digital Preservation)

- 분야: 디지털과 보존
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/digital-preservation/

디지털 자료를 오랜 세월이 지나도 읽고 쓸 수 있도록 지키는 일입니다. 파일 형식이나 프로그램이 낡아 못 쓰게 되는 문제를 막기 위해 형식 변환, 여러 곳 복사, 파일 손상 검사 등을 합니다. 국제 표준 모형으로 OAIS(ISO 14721)가 있습니다.

관련어: 보존(preservation), 웹 아카이빙(web-archiving), 디지털화(digitization), 메타데이터(metadata)
근거: ISO 14721:2025 Open Archival Information System (OAIS) Reference Model <https://www.iso.org/standard/87471.html>
