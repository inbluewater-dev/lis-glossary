# 참고자료 (Reference Material / Reference Work)

- 분야: 장서와 자료
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/reference-material/
- 다른 이름: 참고도서, lexicon, vocabulary, 어휘사전, 어휘집

처음부터 끝까지 읽기보다 필요한 부분을 찾아보도록 만든 자료입니다. 사전, 백과사전, 연감, 지도책, 인명록 등이 있으며, 보통 대출하지 않고 도서관 안에서 이용합니다.

관련어: 3차 자료(tertiary-source), 참고서비스(reference-service)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
