# 국제십진분류법 (Universal Decimal Classification (UDC))

- 분야: 분류와 주제
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/udc/
- 다른 이름: UDC

벨기에의 오틀레와 라퐁텐이 듀이십진분류법을 바탕으로 만든 분류표입니다. 콜론(:)이나 더하기(+) 같은 기호로 여러 주제를 조합해 복잡한 주제도 세밀하게 나타낼 수 있어, 유럽의 전문도서관 등에서 많이 씁니다.

관련어: 듀이십진분류법(ddc), 패싯 분류(facet-classification), 분류표(classification-scheme)
근거: UDC Consortium, Universal Decimal Classification <https://udcc.org/>
