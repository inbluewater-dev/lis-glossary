# 제적 (Weeding / Deselection)

- 분야: 장서와 자료
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/weeding/
- 다른 이름: 장서 솎아내기

낡거나 내용이 오래되었거나 더 이상 이용되지 않는 자료를 장서에서 빼는 일입니다. 서가를 쓸모 있게 유지하기 위한 정상적인 장서관리 과정의 일부입니다.

관련어: 장서개발(collection-development), 장서(collection)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
