# 시소러스 (Thesaurus)

- 분야: 분류와 주제
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/thesaurus/
- 다른 이름: 통제어휘집

색인과 검색에 쓰는 낱말들을 모아 서로의 관계를 정리해 둔 어휘 사전입니다. 대신 쓸 말(USE), 더 넓은 말(BT), 더 좁은 말(NT), 관련 있는 말(RT) 같은 관계를 표시해 검색어를 고르고 넓히는 데 도움을 줍니다.

예: 「자동차」의 좁은 말(NT) → 「전기자동차」, 넓은 말(BT) → 「교통수단」.

관련어: 통제어휘(controlled-vocabulary), 주제명표목(subject-heading), 색인(index)
근거: ISO 25964 Thesauri and interoperability with other vocabularies <https://www.iso.org/standard/53657.html>
