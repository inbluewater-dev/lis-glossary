# 초간본 (Editio Princeps)

- 분야: 책과 서지학
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/editio-princeps/
- 다른 이름: 초인본, 에디티오 프린켑스, ED. PR.

손으로 베껴 전해지던 작품이 처음으로 인쇄되어 나온 판입니다. 특히 그리스·로마 고전의 첫 인쇄본을 가리킬 때 많이 씁니다. 출판된 책의 첫 판을 뜻하는 일반적인 「초판」보다 좁은 말입니다.

관련어: 판(edition), 고서(old-book)
근거: Philip Gaskell, A New Introduction to Bibliography (Oxford University Press, 1972)
