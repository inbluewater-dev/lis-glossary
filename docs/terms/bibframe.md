# BIBFRAME (Bibliographic Framework)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/bibframe/
- 다른 이름: 빕프레임

미국 의회도서관이 MARC를 대신하기 위해 개발해 실제로 쓰기 시작한 새로운 서지 데이터 모형입니다. 서지 정보를 웹의 연결데이터 방식으로 표현해, 도서관 데이터가 웹의 다른 데이터와 이어지도록 하는 것이 목표입니다.

관련어: MARC(marc), 연결데이터(linked-data), IFLA LRM(ifla-lrm)
근거: Library of Congress, BIBFRAME <https://www.loc.gov/bibframe/>
