# 저자성 (Authorship)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/authorship/
- 다른 이름: 저작자성

어떤 저작의 내용을 만들어 낸 책임이 누구에게 있는가 하는 개념입니다. 목록에서는 저자성이 책임표시를 적고 기본표목이나 저작의 접근점을 정하는 근거가 되어, 「누구의 책인가」로 자료를 찾게 해 줍니다. 단체나 여러 사람이 함께 만든 자료에서 누구를 저자로 볼지는 목록규칙마다 다르게 정해 왔습니다.

관련어: 책임표시(statement-of-responsibility), 기본표목(main-entry), 단체표목(corporate-heading), 필명(pseudonym)
근거: Michael Carpenter, Elaine Svenonius (eds.), Foundations of Cataloging: A Sourcebook (Libraries Unlimited, 1985); RDA: Resource Description and Access (RDA Toolkit) <https://www.rdatoolkit.org/>
