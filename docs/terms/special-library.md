# 전문도서관 (Special Library)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/special-library/

특정한 기관이나 분야의 필요에 맞춰 그 분야 자료를 집중적으로 모은 도서관입니다. 연구소, 기업, 병원, 법원, 박물관 등에 딸린 도서관이 대표적입니다.

관련어: 도서관(library), 회색문헌(grey-literature)
근거: 대한민국 도서관법 (국가법령정보센터) <https://www.law.go.kr/법령/도서관법>
