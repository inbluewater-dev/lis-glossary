# 분류 (Classification)

- 분야: 분류와 주제
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/classification/

자료를 주제나 성격이 비슷한 것끼리 모으고, 기호를 붙여 일정한 순서로 배열하는 일입니다. 분류 덕분에 같은 주제의 책이 서가에 나란히 꽂혀 있어 둘러보며 찾을 수 있습니다.

관련어: 분류표(classification-scheme), 한국십진분류법(kdc), 듀이십진분류법(ddc), 청구기호(call-number)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
