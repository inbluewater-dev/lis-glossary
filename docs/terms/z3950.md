# Z39.50 (Z39.50 Information Retrieval Protocol)

- 분야: 식별자와 표준
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/z3950/

서로 다른 도서관의 목록 데이터베이스를 하나의 방식으로 검색할 수 있게 해 주는 통신 규약입니다. 도서관이 다른 기관의 서지 레코드를 검색해 가져올 때 오래전부터 써 왔습니다.

관련어: OPAC(opac), 서지 레코드(bibliographic-record), OAI-PMH(oai-pmh)
근거: ANSI/NISO Z39.50 / ISO 23950 (Library of Congress Z39.50 Maintenance Agency) <https://www.loc.gov/z3950/agency/>
