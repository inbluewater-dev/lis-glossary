# 듀이십진분류법 (Dewey Decimal Classification (DDC))

- 분야: 분류와 주제
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/ddc/
- 다른 이름: DDC, 듀이

미국의 멜빌 듀이가 1876년에 처음 발표한 분류표로, 세계에서 가장 널리 쓰이는 십진 분류법입니다. 지금은 OCLC가 관리하며, 한국십진분류법도 이 구조를 본떠 만들었지만 주류의 배열은 서로 다릅니다.

관련어: 한국십진분류법(kdc), 국제십진분류법(udc), 분류표(classification-scheme)
근거: OCLC, Dewey Decimal Classification (DDC) 23판(2011) 및 이후 갱신판 <https://www.oclc.org/en/dewey.html>
