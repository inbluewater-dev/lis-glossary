# 전자책 (E-book)

- 분야: 장서와 자료
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/ebook/
- 다른 이름: 이북, 디지털 책

종이 대신 디지털 파일로 만들어 화면으로 읽는 책입니다. 도서관에서는 보통 사들이는 대신 이용 권한(라이선스)을 얻어 제공하므로, 동시 이용자 수나 이용 기간에 제한이 있을 수 있습니다.

관련어: 디지털도서관(digital-library), 장서(collection)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
