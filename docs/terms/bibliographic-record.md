# 서지 레코드 (Bibliographic Record)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/bibliographic-record/
- 다른 이름: 서지 기록

자료 하나를 설명하는 서지 정보를 목록 규칙과 형식에 맞춰 기록한 단위입니다. 도서관 검색에서 책 한 권을 눌렀을 때 보이는 상세 정보 화면이 서지 레코드를 보여 주는 것입니다.

관련어: 목록(catalog), MARC(marc), 메타데이터(metadata), 접근점(access-point)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>; Library of Congress, MARC 21 Formats <https://www.loc.gov/marc/>
