# 더블린 코어 (Dublin Core)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/dublin-core/

웹 자원을 비롯한 다양한 자료를 간단히 설명하기 위한 메타데이터 표준입니다. 제목, 작성자, 주제, 날짜, 형식 등 15개의 기본 요소로 이루어져 있어 도서관 밖에서도 널리 쓰입니다. 1995년 미국 오하이오주 더블린에서 열린 회의에서 이름이 붙었습니다.

관련어: 메타데이터(metadata), OAI-PMH(oai-pmh)
근거: DCMI Metadata Terms / ISO 15836 <https://www.dublincore.org/>
