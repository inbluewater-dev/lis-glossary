# 오픈액세스 (Open Access (OA))

- 분야: 학술정보와 저작권
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/open-access/
- 다른 이름: OA, 오픈 액세스, 개방형 접근

학술 논문 등 연구 결과를 누구나 인터넷에서 비용 없이 읽고 내려받을 수 있게 공개하는 것입니다. 2002년 부다페스트 오픈액세스 선언(BOAI)으로 널리 알려졌습니다. 학술지에서 바로 공개하는 방식(골드 OA)과 저자가 리포지터리에 따로 올리는 방식(그린 OA)이 있습니다.

관련어: 기관 리포지터리(institutional-repository), 크리에이티브 커먼즈 라이선스(creative-commons), 학술지(academic-journal)
근거: Budapest Open Access Initiative (2002) <https://www.budapestopenaccessinitiative.org/>
