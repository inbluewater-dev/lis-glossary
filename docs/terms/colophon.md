# 간기 (Colophon)

- 분야: 책과 서지학
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/colophon/
- 다른 이름: 콜로폰, 판권지, 판권면

책의 끝(또는 앞)에 언제, 어디서, 누가 찍어 냈는지를 적은 부분입니다. 표제지가 생기기 전의 서양 초기 인쇄본과 우리 고서에서 중요한 정보원이며, 오늘날 우리 책의 「판권지(판권면)」가 같은 역할을 합니다.

관련어: 권두표제(caption-title), 고서(old-book), 판(edition)
근거: Philip Gaskell, A New Introduction to Bibliography (Oxford University Press, 1972)
