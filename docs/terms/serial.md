# 연속간행물 (Serial)

- 분야: 장서와 자료
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/serial/

끝을 정하지 않고 같은 제목으로 권호를 이어 가며 계속 나오는 출판물입니다. 신문, 잡지, 학술지, 연감 등이 해당하며, ISSN으로 식별합니다.

관련어: 정기간행물(periodical), 학술지(academic-journal), 국제표준연속간행물번호(issn), 단행본(monograph)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>; ISSN International Centre / ISO 3297 <https://www.issn.org/>
