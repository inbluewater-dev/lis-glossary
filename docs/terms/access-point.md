# 접근점 (Access Point)

- 분야: 목록규칙과 표목
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/access-point/

이용자가 목록에서 자료를 찾아낼 때 실마리가 되는 이름이나 낱말입니다. 저자명, 서명(제목), 주제명 등이 대표적인 접근점입니다. 예전에는 「표목」이라고 불렀습니다. 「접근점」이라는 말은 영미목록규칙 제2판(AACR2, 1978) 때부터 쓰였고, 국제목록원칙(2009)과 RDA에서 「표목」을 대신하는 기본 용어가 되었습니다.

관련어: 표목(heading), 전거형 접근점(authorized-access-point), 전거제어(authority-control), 기본표목(main-entry), 한정어구(qualifier), 주제명표목(subject-heading)
근거: RDA: Resource Description and Access (RDA Toolkit) <https://www.rdatoolkit.org/>; ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
