# 접근점 (Access Point)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/access-point/
- 다른 이름: 표목

이용자가 목록에서 자료를 찾아낼 때 실마리가 되는 이름이나 낱말입니다. 저자명, 서명(제목), 주제명 등이 대표적인 접근점입니다.

관련어: 전거제어(authority-control), 기본표목(main-entry), 한정어구(qualifier), 주제명표목(subject-heading), 서지 레코드(bibliographic-record)
근거: RDA: Resource Description and Access (RDA Toolkit) <https://www.rdatoolkit.org/>; ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
