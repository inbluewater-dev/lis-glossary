# 서지 (Bibliography)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/bibliography/
- 다른 이름: 참고문헌 목록, 문헌 목록

책이나 자료에 관한 정보(제목, 저자, 출판사, 출판연도 등)를 뜻하기도 하고, 그런 정보를 모아 놓은 목록을 뜻하기도 합니다. 논문 끝의 「참고문헌」도 서지의 한 형태입니다.

관련어: 서지 레코드(bibliographic-record), 인용(citation), 3차 자료(tertiary-source)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
