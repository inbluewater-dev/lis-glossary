# 목록규칙 (Cataloging Code / Cataloging Rules)

- 분야: 목록규칙과 표목
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/cataloging-code/
- 다른 이름: 목록규칙집, 목록법

도서관 목록을 일관되게 만들기 위해 무엇을 어떤 형태로 기록하고 어떤 접근점을 둘지를 정해 놓은 규칙의 체계입니다. 파니치의 91개조 규칙(1841), 커터의 사전체 목록 규칙(1876), 영미목록규칙(AACR2), RDA, 우리나라의 한국목록규칙(KCR) 등이 이어져 왔습니다.

관련어: 파니치의 91개조 규칙(panizzi-91-rules), 한국목록규칙(kcr), RDA(rda), ISBD(isbd), 목록(catalog)
근거: Michael Carpenter, Elaine Svenonius (eds.), Foundations of Cataloging: A Sourcebook (Libraries Unlimited, 1985); Charles A. Cutter, Rules for a Printed Dictionary Catalogue (1876); RDA: Resource Description and Access (RDA Toolkit) <https://www.rdatoolkit.org/>; 한국도서관협회, 한국목록규칙(KCR)
