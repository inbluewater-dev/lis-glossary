# 절단검색 (Truncation)

- 분야: 정보검색
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/truncation/
- 다른 이름: 절단 검색, 와일드카드 검색

낱말의 일부만 입력하고 나머지를 기호(* 등)로 비워 두어, 그 부분으로 시작하거나 끝나는 낱말을 한꺼번에 찾는 방법입니다.

예: 「librar*」로 검색하면 library, libraries, librarian이 모두 찾아집니다.

관련어: 불리언 검색(boolean-search), 정보검색(information-retrieval)
근거: C. D. Manning, P. Raghavan, H. Schütze, Introduction to Information Retrieval (Cambridge University Press, 2008) <https://nlp.stanford.edu/IR-book/>
