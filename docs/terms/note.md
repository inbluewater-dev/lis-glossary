# 주기 (Note)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/note/
- 다른 이름: 주기사항

정해진 다른 영역에 넣기 어려운 정보를 보충해 적는 영역입니다. 원서명, 수록 내용, 서지 참고, 이용 제한, 소장본만의 특징 등을 자유로운 문장으로 적습니다.

관련어: 서지기술 영역(isbd-areas), 서지 레코드(bibliographic-record)
근거: IFLA, ISBD: International Standard Bibliographic Description, Consolidated Edition (2011) <https://www.ifla.org/isbd-editions/>
