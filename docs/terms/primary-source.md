# 1차 자료 (Primary Source)

- 분야: 기초 개념
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/primary-source/
- 다른 이름: 1차 문헌, 원자료

어떤 사건이나 연구를 직접 겪거나 수행한 사람이 처음 남긴 자료입니다. 일기, 편지, 당시의 신문 기사, 사진, 실험 결과를 처음 발표한 논문, 법령 원문 등이 여기에 속합니다.

관련어: 2차 자료(secondary-source), 3차 자료(tertiary-source), 아카이브(archives)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
