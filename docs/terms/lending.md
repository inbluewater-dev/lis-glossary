# 대출 (Lending / Circulation)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/lending/
- 다른 이름: 대출반납, 열람대출

도서관 자료를 정해진 기간 동안 도서관 밖으로 빌려 가도록 하는 서비스입니다. 대출·반납·예약·연장을 묶어 「대출 업무」라고 부르며, 요즘은 RFID를 이용한 무인 대출기도 널리 쓰입니다.

관련어: 상호대차(interlibrary-loan), RFID(rfid), 공공도서관(public-library)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
