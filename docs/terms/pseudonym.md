# 필명 (Pseudonym)

- 분야: 목록규칙과 표목
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/pseudonym/
- 다른 이름: 가명, 펜네임

저자가 본명 대신 쓰는 이름입니다. 목록에서는 어느 이름을 표목으로 삼을지가 문제가 되는데, 오늘날 RDA는 한 사람이 쓴 서로 다른 필명을 각각 별개의 서지적 정체성으로 보고 관계로 이어 줍니다.

예: 시인 이상(본명 김해경)의 작품은 보통 「이상」으로 찾고, 「김해경」에서는 참조로 이어 줍니다.

관련어: 저자성(authorship), 참조(cross-reference), 전거제어(authority-control)
근거: RDA: Resource Description and Access (RDA Toolkit) <https://www.rdatoolkit.org/>; Michael Carpenter, Elaine Svenonius (eds.), Foundations of Cataloging: A Sourcebook (Libraries Unlimited, 1985)
