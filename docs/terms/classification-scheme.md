# 분류표 (Classification Scheme)

- 분야: 분류와 주제
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/classification-scheme/
- 다른 이름: 분류체계, 분류법

지식 전체를 주제별로 나누고 각 주제에 기호를 정해 놓은 표입니다. 한국십진분류법(KDC), 듀이십진분류법(DDC), 국제십진분류법(UDC), 미국의회도서관분류법(LCC) 등이 있습니다.

관련어: 한국십진분류법(kdc), 듀이십진분류법(ddc), 국제십진분류법(udc), 패싯 분류(facet-classification)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
