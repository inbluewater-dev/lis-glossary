# 도서기호 (Book Number)

- 분야: 분류와 주제
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/book-number/
- 다른 이름: 저자기호

같은 분류기호를 가진 책들을 서가에서 다시 순서대로 줄 세우기 위해 붙이는 기호입니다. 주로 저자 이름과 서명의 첫 글자로 만들며, 우리나라에서는 「리재철 한글순 도서기호법」이, 서양 책에는 「커터-샌본 저자기호표」가 많이 쓰입니다.

관련어: 청구기호(call-number), 분류(classification)
근거: 리재철, 『한글순도서기호법』(한국도서관협회); Cutter-Sanborn Three-Figure Author Table
