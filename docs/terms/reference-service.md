# 참고서비스 (Reference Service)

- 분야: 도서관과 서비스
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/reference-service/
- 다른 이름: 참고봉사, 레퍼런스 서비스, 정보서비스

사서가 이용자의 질문을 받아 필요한 자료나 정보를 찾아 주거나, 찾는 방법을 안내하는 서비스입니다. 도서관 안내 데스크뿐 아니라 전화, 채팅, 이메일로도 이루어집니다.

예: 「조선시대 과거 시험에 관한 쉬운 책이 있나요?」라는 질문에 알맞은 책과 자료를 찾아 주는 것.

관련어: 참고면담(reference-interview), 참고자료(reference-material), 사서(librarian)
근거: ISO 5127:2017 Information and documentation — Foundation and vocabulary <https://www.iso.org/standard/59743.html>
