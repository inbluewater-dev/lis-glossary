# 시그니처 (Signature (Mark) / Register)

- 분야: 책과 서지학
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/signature-mark/
- 다른 이름: 접장 기호, 레지스터

접은 종이 묶음(접장)을 순서대로 엮도록 각 묶음의 첫 장(과 앞쪽 몇 장) 아래에 인쇄한 문자나 숫자입니다. 시그니처 문자의 차례, 또는 그것을 적어 둔 목록을 「레지스터」라고 하며, 쪽 번호가 없는 옛 책에서는 시그니처로 위치를 가리키고 빠진 장이 없는지 확인합니다.

관련어: 판형(book-format), 고서(old-book)
근거: Philip Gaskell, A New Introduction to Bibliography (Oxford University Press, 1972)
