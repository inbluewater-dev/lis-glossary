# 웹 아카이빙 (Web Archiving)

- 분야: 디지털과 보존
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/web-archiving/

사라지거나 바뀌기 쉬운 웹사이트를 일정한 때마다 수집해 그 모습을 그대로 보존하는 일입니다. 국가도서관들이 주로 맡으며, 우리나라에서는 국립중앙도서관이 「OASIS」라는 이름으로 운영합니다.

관련어: 디지털 보존(digital-preservation), 국가도서관(national-library)
근거: International Internet Preservation Consortium (IIPC) <https://netpreserve.org/>; 국립중앙도서관 <https://www.nl.go.kr/>
