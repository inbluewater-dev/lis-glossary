# RDA (RDA: Resource Description and Access)

- 분야: 목록과 메타데이터
- 주소: https://inbluewater-dev.github.io/lis-glossary/terms/rda/
- 다른 이름: 자원의 기술과 접근

자료를 기술하고 접근점을 정하는 방법을 정한 국제 목록 규칙입니다. 영미목록규칙(AACR2)의 뒤를 이어 2010년에 나왔으며, 개념 모형(FRBR, 뒤에는 IFLA LRM)을 바탕으로 만들어져 디지털 환경에 맞게 설계되었습니다.

관련어: IFLA LRM(ifla-lrm), 한국목록규칙(kcr), 목록(catalog), 접근점(access-point)
근거: RDA: Resource Description and Access (RDA Toolkit) <https://www.rdatoolkit.org/>
